# FarmDirect: Modern Agricultural Marketplace & Weather Intelligence

A responsive Web Application designed to connect farmers directly with consumers while providing real-time weather analytics and smart agricultural recommendations.

---

## 🚀 Key Features

* **Direct Marketplace**: Interactively list and browse crops, search by name, and filter by cultivation type (e.g. Organic vs. Conventional).
* **Real-time Agro-Weather Sync**: Fetches real-time localized weather reports, temperature gauges, and humidity rates.
* **Soil Analytics Dashboard**: Graphical gauges displaying key measurements like soil moisture levels, pH levels, and nitrogen values.
* **Smart Agricultural Recommendations**: An algorithms-based suggestion engine generating optimized advice for irrigation, soil health, and harvesting based on active weather patterns.
